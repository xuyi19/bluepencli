## 这两个文档是什么

- **材料汇编.md**：每套卷的完整题面材料，按「材料N」分节。
- **参考答案汇编.md**：每题的题干、要求与参考答案，练习完再对答案。
- 练习时程序默认**只展示本题引用的那几则**（v0.17.0 起按题裁材料），本汇编保留整卷便于通读。

## 什么没有在这里

**采分点 / 评分细则**。它们属于"标准层"，写出采分点等于泄题，只随批改过程注入，不落任何导出文档。
