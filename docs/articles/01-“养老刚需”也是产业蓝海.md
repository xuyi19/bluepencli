# “养老刚需”也是产业蓝海

逢年过节，想给父母买点趁手好物？未来将迎来更多选择。

《扩大消费“十五五”规划》明确提出，扩大银发产品有效供给。面向老年人品质生活需要，加强适老化日用产品、老年休闲陪护产品、功能性老年服饰、康复辅助器具等的研发设计生产，开发应用养老服务机器人、多功能护理床、健康监测设备等急需产品。

截至2025年，我国老年人口占比已达23%。综合多方面情况看，目前银发产品持续增加，但供给规模、层次与需求相比仍有差距。这不仅意味着民生痛点，也是亟待挖掘的产业蓝海。

适老化产品增速显著，但供给规模和人口基数相比仍存在明显不足

银发产品都有啥？

在电商平台上搜索“银发”“适老化”等关键词，助行器、助浴器、各类扶手、理疗仪器、康复训练器械、呼叫按铃等映入眼帘。功能辅助，是这些产品呈现的一大特点，也是不少老年人群的“刚需”。

国家统计局数据显示，截至2025年末，全国60周岁及以上老年人口32338万人，占总人口的23.0%。市场监管总局发布的数据显示，截至2025年4月底，全国消费品品种总量21860.4万种，其中适老化产品总量21.6万种，涉及近1万家企业。拐杖、轮椅、代步车等助行产品，日常生活辅助用品，居家安全产品，护理用品，康复训练器材，健康监测设备等均增长明显。

“整体数据显示，尽管适老化产品增速显著，但供给规模和人口基数相比仍存在明显不足，市场开发空间可观。”市场监管总局有关负责人表示。

银发群体实际感受如何？

中国老龄协会今年发布的《银发消费的现状与趋势》报告显示，从备老和银发群体自述的需求和消费情况看，功能性食品及衣着需求比例最高，超出70%；居家适老化改造处于第二梯队，智慧产品、抗衰老产品及技术处于第三梯队。“总体上看，绝大部分领域的需求比例明显高于消费比例，备老和银发群体的需求有待进一步满足。”报告称。

传统观点认为老年人“重储蓄、轻消费”，但随着越来越多受过良好教育、收入水平较高的人群进入老年或备老阶段，这种情况正在发生变化。

近期发布的《上海市银发经济发展报告（2025）》显示，“新退休群体”成为消费主力，文娱旅游、养生保健、智能好物等品质消费需求暴涨，代际孝亲消费、备老消费同步崛起，银发消费生态持续丰富。从“存钱养老”到“乐享晚年”，上海银发消费完成从基础刚需向品质享受的转型，成为城市消费新增长极。

全国层面，看几组数据：2025年，居家适老化改造纳入家装厨卫“焕新”补贴范围，带动适老产品销售721万件；全年实施适老化无障碍改造小区9000余个；全国开行旅游列车2485列，旅居养老人次超8000万。

“20世纪50年代以后出生的老年人，随着收入水平逐步提升，生活方式受到互联网、人工智能、大数据等新技术影响，消费需求和消费偏好均呈现多样化特征。”南开大学经济学院教授原新认为，根据人口发展规律，50后以及部分60后现已步入老龄阶段。随着这一群体规模逐步扩大，他们对美好生活的需求正催生出一个生机盎然的消费领域。

研发生产脚步加快，银发经济相关赛道增长动能持续增强

消费的变化在市场上有哪些体现？

松下电器中国东北亚事业智感健康事业推进本部康养营销部部长王祺举了制氧机的例子：这款产品最早推出时市场反响平平，但最近两年销量迎来爆发。“最主要还是大家的健康需求增加了。”王祺说，它的用户不仅限于有呼吸不畅等困扰的人群，很多银发群体也会选择制氧机来改善居家环境，提升生活品质。

公开信息显示，我国基本形成“9073”养老服务格局，即90%左右的老年人居家养老，7%左右的老年人依托社区支持养老，3%的老年人入住机构养老。可见，家庭依旧是养老的主要阵地，在这种情况下，如何打造一个健康舒适的适老化空间，成为众多企业发展的机会所在。

不仅仅是制氧机，王祺介绍，可以灵活调节睡眠状态、实时监测健康状态的智能床；电动轮椅、移动扶手、按摩仪等多款产品都受到市场青睐。相关部门发布的老年用品产品推广目录，也包含了家庭陪护机器人、智能适老型电热水器、适老化智能马桶盖、多功能沙发、康复训练辅具等多种优质产品。

有人问：适老化产品价格会更贵吗？

“有的产品确实主打科技、智能，通过这些手段更好解决银发群体的痛点；但也有的产品只需在设计上精准匹配老年人的需求和特点，并没有成本上的增加。”王祺介绍，比如好的助行器，轻便实用，但价格并不高，很受欢迎。

不过，不管什么价位，好的适老化产品，一定要基于需求洞察，实打实满足银发群体的日常需要。松下开发了一款淋浴椅，主要用来解决老人行动不便、洗澡怕滑等问题，外观看起来似乎并不复杂，但背后有许多人性化的设计。比如，配色为什么用橘黄？王祺解释，因为对一些特殊人群例如阿尔茨海默病患者来说，颜色太艳丽会刺激感官，太暗淡又容易导致视觉不清晰，所以橘黄是最佳的选择。

“我们会不断加强适老化产品研发，针对银发群体的真实需求持续优化迭代产品，让他们乐用、爱用。”王祺说。

众多企业都在加快研发、生产的脚步，银发经济相关赛道增长动能持续增强。国家税务总局增值税发票数据显示，2025年上半年，适老类健身器材制造、康复辅具制造、营养保健食品制造销售收入同比分别增长14.7%、12.1%、6.9%；智慧养老技术服务、老年智能与可穿戴装备制造销售收入增速更为显著，分别达到33.7%和32.6%。同期，全国从事银发产品生产制造的主体户数同比增长14.1%。

原新认为，当前，老年人多元化、差异化、个性化的需求正变得越来越旺盛和迫切。推动银发经济扩容提质，要加强老年用品研发和推广，不断丰富养老服务场景，强化质量监管，能够更好满足老年人需求。

懂科技、爱时尚、有活力、重品质，银发经济需求扩容与结构升级并行

除了“康复”“辅助”等关键词之外，越来越多懂科技、爱时尚、有活力、重品质的老年人正在进入大众视野，他们关于快乐、发展和美的需求也越来越被市场重视。

“过去，老年人群的美妆消费多是‘被动选择’——子女过年送的护肤品、婚礼场合临时买的彩妆。而现在，‘主动悦己’逐渐成为主流。”欧莱雅中国相关负责人介绍，银发族在护肤和彩妆产品品类使用数量上持续增加，也更加愿意尝试新的护肤、美妆和生活方式。

一份来自欧莱雅的市场调查显示，91%的消费者认为年龄只是一个数字，77%的消费者愿意在“银发”时去尝试新事物。“新银发群体普遍具备‘有经济实力、有时间、有心情、有要求’的特点，他们的消费潜力巨大，而且已从‘生存型’向‘发展型’‘享受型’全面跃升。”该负责人介绍，基于此，欧莱雅正以“新龄美”理念为引领，持续加码长寿科学领域的研发创新，强化精准诊断、外用护肤/护发、美容仪器、口服营养与定制服务等五大核心产品支柱的落地。

《上海市银发经济发展报告（2025）》显示，银发群体不同年龄段呈现“体验—规划—刚需—照护”递进特征；不同收入群体呈“基础—多元—高端”分层的特点。文娱社交旅游和养生保健为增支意愿最强领域，构成银发经济增长核心引擎。

过去3年间，松下在中国的智感健康相关业务连续保持每年两位数以上的增长。“未来银发经济一定还会迎来爆发期。”王祺认为，需求端，银发群体数量在持续增加，加上家庭结构变化，更多老年人会面临备老和养老的课题，需求还会持续释放；供给端，产业在不断深耕积累，很多适老化产品呈现可观的增长趋势。随着产业厚度增加，更丰富的多元产品将更好满足银发人群需求。

再从市场现状来看，手机、家电等产品人均保有量较高，市场需求更多来自更新需要，而适老化产品普及空间大，还有巨大的增长潜力。“这也是我们深耕产业的巨大动力。”王祺说。

相关报告显示，在人口老龄化加速、预期寿命提升等趋势叠加的背景下，高品质养老需求持续释放。与此同时，老年阶段延长、家庭结构小型化以及新老年群体代际更替，推动银发需求由基础保障型向品质型加速演进，银发经济进入需求扩容与结构升级并行的发展阶段。

在品质升级等领域，一些城市已经走在前列。在上海，毫米波雷达无感监测、跌倒侦测护眼灯等非穿戴设备广泛应用于养老院；智能防抖手环、轻量化外骨骼机器人纳入康复辅具租赁目录；半人形养老护理机器人预计2026年正式投放市场。

“增进老年人福祉，是发展银发经济的出发点和落脚点。”原新认为，如今我们在满足老年人的需求、回应老年人的期待方面有了更加雄厚的物质基础、更加先进的技术支撑、更加可靠的政策支持。发展银发经济，加快养老科技和信息化发展应用，将为老龄事业和老龄产业发展注入充足动力。
