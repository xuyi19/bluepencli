# 蓝笔申论 · 使用说明书

> 面向使用者的完整说明。写给"拿到这个软件的人"——不讲实现，只讲它能帮你做什么、怎么用。

---

## 一句话介绍

蓝笔申论是一个**本地优先**的公考申论练习与 AI 批改工具：你写答案，几位风格不同的"AI 阅卷老师"独立打分、逐句批注，分歧大的还会开圆桌辩论，最后给出一份带采分点对照、能力画像和改进建议的完整报告。**所有作答与批改记录都存在你自己的电脑上。**

---

## 一、三种打开方式

| 形态 | 适合场景 | 说明 |
|---|---|---|
| **桌面版**（推荐） | 日常使用 | 双击即用，不用装 Node/Python，数据在exe同级 |
| 网页版 | 自己部署/开发 | 前端 + 后端网关分开跑 |
| 单文件 HTML | 发给别人试用 | 一个 HTML 文件，浏览器打开就能用 |

三种形态功能一致，记录互不相通（各自存在各自的存储里）。

**第一步永远是配置 API Key**：设置页填入大模型服务的地址、Key、模型名（支持任意 OpenAI 兼容接口，如 DeepSeek、智谱、月之暗面）。填完点「测试连接」，通了就能批改。没有 Key 时除批改外的功能（题库、文章库、历史查看）都可用。

## 二、核心流程：写一篇 → 批一次

练习页默认帮你载入「今日一练」（按日期轮换的真题），也可以从题库自选。

1. **看材料写答案**：材料区默认只显示这道题引用的那几则（不用通读整卷），方格纸作答区实时计字数、超字数会标红
2. **选阅卷老师**：1~5 位任选（见下节）
3. **交卷批改**：各老师并行独立批改 → 有分歧自动触发圆桌辩论 → 组长合议出最终分
4. **看报告**：最终分、可信度评估、逐句批注（色标段落）、采分点对照、各老师意见、修改建议

### 两种练习模式

- **训练模式**（默认）：随时批改、随时看参考答案，适合日常消化一道题
- **考场模式**：落笔即倒计时（大作文默认 60 分钟、贯彻执行 40、其他 30，可调），最后 5 分钟变红提醒，交卷需二次确认，**时间到自动交卷**——按真实考场练节奏

## 三、阅卷老师：一位到五位

| 老师 | 判分视角 |
|---|---|
| 袁东 | 按词给分 · 采分词裁判 |
| 周泰然 | 材料逻辑 · 要点处理裁判 |
| 白鹭 | 应题意识 · 形式回应裁判 |
| Kiwi | 框架体系 · 分类逻辑裁判 |
| 李崇立 | 实用踩点 · 表述规范裁判 |

- **一位老师**：最便宜最快，直接出分
- **两位**：加权合并，标注谁的分被采信更多
- **三位及以上**：完整圆桌——先并行独立打分，分差超过阈值自动**开辩论**（每道争议点给裁定与依据），最后**组长合议**融合成一份结论。人越多越稳，也越贵越慢

> 费用与老师数量成正比。日常练习建议 1~2 位，模考或重要题再上圆桌。

## 四、题库

- **国考真题**：2010–2021 共 24 套 119 题，随软件内置，含整卷材料与参考答案
- **省考真题**：河北省考 2008–2021 共 16 卷已入库（题库页可按体系筛选「国考 / 省考-河北」）；其他省份陆续接入
- **私有题库**：2022 年起的近三年真题不随软件分发，由作者发 `.bpq` 加密题库包——拖进题库页任意位置，输入口令即导入（**包和口令分两条路发**，这是设计）
  - **导入时你会看到什么**：一条条列出来 —— 读取文件 → 格式与校验和 → 签名校验（会告诉你签发者）→ 解密 → 水印（**标着你的专属标识**）→ 写入题库。哪一步不对就停在哪一步，不用猜（"签名不通过"和"口令不对"是完全不同的两件事，会分开说）
  - **导入后能管**：题库页右上角「**我的题库**」按批次列出你导入过的包——套数/题数、导入时间、文件名、水印、签发者、包含哪些卷。想删就**整批删**（二次确认），不会影响内置真题和你自己录入的题。**要再练需要重新导入**，所以删之前想清楚
- **仿真题**：15 道按真题风格自编，适合快速专项练
- **自建题**：自己粘贴材料与题干录入，一样能批改

练习时程序自动只带本题引用的材料（省 token 也省注意力），但题库页可展开看整卷。

## 五、批改报告怎么读

- **总分与档位**：合议后的最终分；旁边有**可信度**徽标——这个分有多少依据（老师一致性、与程序粗判的吻合度、**标准来源**、阅卷完成度、客观校验、分歧复核），没依据的指标会显示「不适用」而不是编一个数。其中「标准来源」是这道题的采分点**从哪来的**：人工精校的最好，机器预解析的次之，没有标准的会明确标出并说明「换一次批改分数可能就变」
- **逐句批注**：原文色标 + 问题类型 + 改法，来自每位老师的独立意见
- **圆桌记录**：分歧点、各老师立场、裁定与依据——比一个冷冰冰的分数更有信息量
- **修改建议**：按优先级排序，先改哪处说清楚

## 六、复盘与成长

- **历史批改**：每一次练习都自动归档（网页存 IndexedDB，桌面/后端还会落成 `docs/practice/` 下的 .md + .json，能用编辑器直接翻）
- **错题本**：按「栽在几份记录里」排序——反复出现的错误排前面；只栽过一次的收进折叠区，不假装有结论
- **再练一题**：按你的短板推荐下一题（同题型对症 / 跨题型通病两档；依据不足时明确说"暂不推荐"）
- **统计**：平均得分率、最佳成绩、**能力画像六维雷达**（要点覆盖/材料运用/结构条理/审题应题/语言表达/规范体例，由错误类型反推，样本不足 3 篇不画）
- **每日一练**：进练习页就有题，不靠意志力选题

## 八、数据与隐私

- **本地优先**：作答、批改、笔记全在你电脑上；后端只记任务级指标（模式/分数/耗时/token 用量），没有用户系统、没有注册登录
- **可离线**：后端不在时自动退回浏览器本地存储，功能不缺
- **成本透明**：设置页看得到每次批改的调用量，费用自己可控
- 采分点/评分细则**永远不展示、不导出**（防止"背答案"），只在批改过程中由系统内部使用

## 九、常见问题

**Q：批改按钮是灰的？**
没配 API Key、没选老师、或作答不足 20 字，看按钮下方提示。

**Q：批改中途能停吗？**
能，批改中页有「停止批改」，已完成的老师分数保留。

**Q：换电脑/换浏览器记录还在吗？**
桌面版在 exe 同级的 data 目录；网页版在浏览器 IndexedDB（清浏览器数据会丢，重要记录看后端归档目录）。

**Q：.bpq 题库包导入失败？**
先确认口令正确（口令分批发，别猜）；再确认包没被传输工具改动（每份包带签名，被改过会被拒）。

**Q：为什么有的分数显示「不适用」？**
可信度系统的诚实原则：算不出来的指标不编数。
