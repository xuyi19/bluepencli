# 蓝笔申论 · 题库管理员端 使用说明

> 面向**作者本人**的工具说明书。它不是给考生用的软件，也**永远不会被打进分发给用户的安装包**。

---

## 这是什么

把仓库 `.tools/` 与 `frontend/scripts/` 下那一堆命令行脚本，做成一个**点按钮就能跑**的图形界面（Tauri 2 小应用，约 5.9 MB）。

**设计原则**（三条，都别破坏）：

1. **只当执行器，不重新实现逻辑** —— 界面上每个按钮对应一条真实命令，输出原样回显。脚本改了界面自动跟着变，不存在"两份实现漂移"。
2. **与分发版物理隔离** —— 它含私钥/口令操作入口，绝不进 `release/`、绝不进用户拿到的包。放在 `admin/` 目录，产物 exe 也在那里。
3. **口令与密钥只走环境变量** —— 不进命令行参数（进程列表里看不见），界面不回显、不写日志。

---

## 打开与配置

- 程序：**`release/管理员端/蓝笔申论-题库管理-v0.18.0.exe`**（双击即用，放 release/ 是为了和桌面版统一归置；`release/` 整目录不进版本库，恰好符合"永不随软件分发"）
- **启动不弹控制台**：exe 按 GUI 子系统编译，子进程一律 `CREATE_NO_WINDOW`——跑任何工具都不会闪黑窗；输出只进界面与 `admin-run.log`
- **仓库根**：程序启动时自动向上探测（找 `.tools/admin-bank.mjs`）。放仓库目录树里就不用管；放别处可手动填路径并点「保存」（写进 exe 同级 `admin-config.json`）。
- **依赖**：`node`（自动探测 PATH 与常见安装位置）；Python 脚本**优先用仓库内的 `backend/.venv`**（pdfplumber 等依赖只装在那里），venv 不在才会退回 PATH 上的 python。找不到会明确报错，不会静默失败。

## 十一个工具

### 题库（PDF → 前端数据）
| 按钮 | 做什么 | 参数 |
|---|---|---|
| 盘点题库 | 公开/私有卷、分发包、采分点标准各多少 | 无 |
| PDF 提取真题 | 按 `exams_config.py` 的卷清单把 PDF 提取成结构化 JSON | 卷 id（留空=全量） |
| 编入前端数据 | `out/*.json` → `real-exams/`（≤2021）与 `real-exams-private/`（≥2022） | 无 |
| 生成真题数据说明 | 刷新 `docs/题库/真题数据说明.md`（数字现算） | 无 |

**加一个省份的真题**（以河北为样板）：改 `exams_config.py` 加省配置（`dir` 指向 PDF 目录、`system='省考-XX'`）→ 提取 → 编入 → 汇编。详情见仓库 `.tools/exams/` 里各脚本头注释。

### 分发（加密题库包）
| 按钮 | 做什么 | 参数 |
|---|---|---|
| 打包加密题库包 | 源 JSON → 明文包 → 加密+签名包（含自检） | 收件人、年份范围、口令（必填） |
| 验包 | 验签 + 解密自检：发出去的是不是能打开的那份 | 包文件路径、口令 |

> **口诀不变**：包与口令**分两条路**发；口令批次走 `.tools/exams/issue.mjs` 登记。

### 文档与素材
| 按钮 | 做什么 | 参数 |
|---|---|---|
| 生成题库汇编 | `docs/题库/汇编/` 下按 体系·年份·卷别 的目录树（采分点永不导出） | 是否含私有卷 |
| 生成文章库镜像 | `docs/题库/文章库/` 下按主题分组的可读 md | 无 |

### 标准与回归
| 按钮 | 做什么 | 参数 |
|---|---|---|
| 采分点覆盖盘点 | 多少题有标准、来源分布、缺口清单 | 无 |
| 采分点校验 | 权重合计 vs 题分、id 唯一、字段齐全 | 无 |
| 一键回归测试 | 全部前端测试套件 + pytest（发版前跑这一条） | 无 |

> 采分点**交互式录入**要终端（本界面不提供）：`node .tools/standards/calibrate.mjs --wizard <题id>`

## 典型工作流

**发一份题库包给同学**
1. 「打包加密题库包」：填收件人、年份、口令 → 跑
2. 「验包」：填包路径 + 口令 → 跑，确认能开
3. 包走微信发；口令**另外一条路**（电话/当面）给

**改完代码，准备发版**
1. 「一键回归测试」→ 必须 18/18
2. 桌面版发布走 `cd desktop && npm run publish`（在终端，带探针）
3. 「生成题库汇编」「生成真题数据说明」刷新文档

**加一批新省份真题**
1. 改 `exams_config.py`（照着河北段抄）
2. 「PDF 提取真题」→ 看输出里"材料 N 则 / 题 N 道 / 分值合计"
3. 提取失败的卷标 `skip=True`，人工补或 OCR
4. 「编入前端数据」→「一键回归测试」→ 提交

## 出问题时

- **按钮点了没反应 / 输出区一直空**：看 exe 同级的 **`admin-run.log`**（每次运行的完整输出都会追加到这里）。若日志里也没有内容，说明进程没起来，通常是 node 找不到。
- **状态一直"运行中"**：界面会显示已运行秒数；超过 8 秒无输出会提示。长任务（全量提取、回归测试）几十秒到几分钟都正常。
- **找不到 node.exe**：装 Node.js 或确认 PATH；程序也会试 `C:\Program Files\nodejs\node.exe` 等常见位置。
- **口令报错**：打包/验包口令是**批次化**的，新批次口令不同；拿不准就重新打一份包、用新口令。

## 安全边界（别越线）

- 管理端 exe **绝不**拷进 `release/`、**绝不**发给用户
- 口令、API Key 一律走环境变量；不写进脚本、不写进配置、不提交
- 采分点标准写进公开库（`standards/manual.json`）等于泄题 —— 私有卷标准走 `standards-private/`
- `.tools/exams/keys/`（签名私钥）与 `batches.json`（口令批次）已被 .gitignore 挡住，别手动加回来
