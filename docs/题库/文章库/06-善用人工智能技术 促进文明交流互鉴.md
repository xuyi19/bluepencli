# 善用人工智能技术 促进文明交流互鉴

> 来源：人民论坛 · 2026-08-26 · 正文约 3310 字
> 主题：科技创新
> 原文：https://www.rmlt.com.cn/2026/0824/754906.shtml

---

7月17日，习近平主席在2026世界人工智能大会暨人工智能全球治理高级别会议开幕式上发表题为《携手构建公正合理的全球人工智能治理体系》的主旨讲话，提出“鼓励包容并蓄，促进文明互鉴”，强调“善用人工智能技术增进不同文明的理解和包容，促进不同文明交流互鉴，精心培育各美其美、美美与共的文明百花园”。

文明因交流而多彩，文明因互鉴而丰富。文明交往的范围和深度，历来受到交通条件、语言文字和信息传播方式的影响。从文字和印刷术的发明，到广播电视和互联网的兴起，传播媒介的每一次进步，都在拓展人类相互了解的空间。建立在数字化和网络化基础上的人工智能，则更加直接地参与语言转换、知识组织和内容呈现，既能帮助人们整理和阐释文明成果，也能降低不同文明相互接触的门槛，还有助于人们把握彼此的历史语境和价值内涵。善用人工智能，能够让更多文明成果进入交流场域，进一步推动文明间的理解和包容。

丰富文明交流互鉴的内容

各国在漫长历史中形成的典籍、文物、艺术和知识传统，记录着不同民族认识世界以及协调人与自然、人与社会关系的独特经验。然而，一些文明资料年代久远、散落残缺，或者受文字、载体和保存条件限制，难以进入当代公共文化生活。人工智能在文字识别、图像分析、智能修复和语义关联等方面的应用，使这些文明成果的整理、研究和呈现更加便捷。

人工智能能够提高文明资料整理和研究的效率。借助文字识别，可以把碑刻、手稿、古籍等资料转化为便于检索和研究的文本；借助图像识别和模式分析，可以辅助辨识文物形制、纹饰和残损信息，为专家比对资料、判断关联提供线索；借助语义分析和知识组织技术，可以把散见于不同文献中的人物、事件和概念联系起来，便于研究者系统梳理人物活动、事件演变和概念沿革。人工智能虽然不能代替专家考证和学术判断，但它能扩大资料处理范围，使更多藏于库房、载于文献或存于数据库中的文明资料被更好地挖掘和使用。

人工智能同数字化、三维重建、虚拟现实等技术融合，还能丰富文明成果的呈现方式。文物、遗址和古籍经过数字化保存之后，可以借助智能修复、场景复原和交互展示，更加完整地呈现其形态、功能及其所处的历史环境。《“人工智能+”国际合作倡议》明确提出：“支持利用人工智能传承和发扬各国优秀传统文化，并实现创造性转化和创新性发展。利用智能修复、数字化保存、沉浸式展示等技术为世界各国的文化瑰宝赋予新的生命力。”借助技术应用，专业研究成果得以更好地转化为公众能够接触和理解的文化内容，为不同文明间的交流与理解创造条件。

人工智能也拓展了各国传统文化的当代表达空间。它可以辅助文学艺术创作、文化产品设计和教育资源开发，推动传统题材与现代视听形式、互动方式相结合，使古老文明以更贴近当代生活、适应现代传播的方式呈现。不过，创新表达不能脱离文明成果自身的历史脉络，也不能让技术生成的内容取代人的文化创造。只有在尊重历史真实和文化主体性的基础上发挥技术之长，才能使文明成果既保持自身特色，又能发挥推动当代文明交流的重要作用。

拓展文明交流互鉴的渠道

丰富的文明成果只有跨越语言和空间的阻隔，才能推动文明间的交流互鉴。语言既是文明经验的载体，也是不同文明相互理解所面临的重要门槛。长期以来，典籍译介、影视译制和跨文化传播需要投入大量时间和专业力量，一些使用范围较小的语言因资源有限，更难获得充分译介。人工智能在机器翻译、语音识别、智能字幕和多语种内容生成等方面的进展，为降低语言门槛、扩大文明传播开辟了新的途径。

多语言智能翻译有助于经典文献、思想成果和文学艺术作品跨语种传播，也能为国际会议、文化展览、教育交流和日常交往提供实时语言服务。例如，中国和马来西亚企业联合建设东盟AI多语言译制中心，实现影视内容的快速译制。这一探索表明，人工智能能够提高跨语言内容生产效率，使不同国家的文化产品更加便捷地进入彼此的公共文化空间。随着翻译效率的不断提高，更多原本因语言阻隔而鲜为人知的文明成果，也将获得被了解、被欣赏的机会。

人工智能还在改变人们接触其他文明的方式。智能导览可以根据参观者的语言和知识背景介绍展品，在线教育平台能够向不同地区的学习者提供适合其需要的文明知识，跨媒体转换则把文字、图像和声音组织成更加易于理解的内容。借助这些渠道，更多普通民众特别是青年有机会走近其他文明，专业知识也随之进入更广泛的社会生活，文明对话从专业领域走向更广阔的公共空间。

交流渠道的拓展，应当惠及更多国家和群体。不同国家和语言群体的数据资源、技术基础和应用能力并不均衡，如果只有少数强势语言能够被模型准确识别和表达，人工智能就可能扩大原有的传播差距，使其他语言承载的文明成果更难得到广泛传播，也更难为其他文明所了解。因此，应当帮助更多国家提升开发和运用人工智能的能力。

围绕这一需要，中国提出了一系列务实举措。习近平主席宣布，未来5年中国将面向发展中国家提供5000个人工智能专题研修培训名额，并面向东盟、阿盟、非盟、拉共体、上合组织、金砖国家建设国际人工智能应用合作中心。本次大会期间成立的世界人工智能合作组织，也把尊重各国主权和文明多样性列为基本原则。这些机制和举措主要着眼于人工智能能力建设与国际合作，同时也有助于更多国家根据自身需要开发应用，为不同文明运用新技术表达自身文化、分享自身经验创造条件。文明交流的渠道越开放，参与主体越广泛，不同文明平等对话的社会基础就越坚实。

增进不同文明的理解和包容

文明交流互鉴的要义，正是在接触其他文明成果的基础上，进一步理解其形成的历史条件、现实处境和内在关切，减少由知识缺失和语境错位造成的误解。深化这种理解，还需要看到文明之间长期交往、相互影响的历史。人类文明从来不是在彼此隔绝中发展的，思想、科技、艺术和制度在跨地域传播中不断相互影响、相互借鉴，并在吸收和转化中实现创新。

借助跨语言检索、文献关联和知识图谱，研究者可以在更大范围内比较不同地区的材料，追踪某一概念在不同语言和历史时期中的变化，发现过去不易察觉的文明联系，从而既能更好地认识不同文明的独特贡献，也能更好地理解文明之间相互依存的历史脉络。面向普通使用者，智能问答和个性化学习工具可以根据其知识基础补充历史背景，解释特定制度、礼俗和观念的文化含义。

但技术提供的解释不能代替人与人之间的真实交往。人工智能可以翻译语言、整理材料和辅助分析，却不能自行产生人们在长期交往中逐步积累的理解和信任。人们如何看待其他文明，既取决于获得了多少信息，也取决于是否愿意平等倾听、设身处地理解彼此的经验。只有坚持人的主体地位，才能避免将文明交往简化为机器对信息的处理过程。

善用人工智能，不仅在于发挥其增进文明间相互理解的功能，也在于防范其放大偏见的风险。如果训练资源长期以少数语种和有限文化材料为主，生成内容脱离具体历史背景，算法又一味迎合既有偏好，技术就可能强化刻板印象，甚至使误解传播得更快。因此，应当扩大训练资源对不同语言和文明成果的覆盖面，重视资料来源的可靠性以及生成内容的真实性、完整性，提高人工智能处理不同文化概念和表达的准确性。

在人工智能领域尊重文明多样性，也是国际社会的普遍共识。《2026世界人工智能大会暨人工智能全球治理高级别会议主席声明》提出：“尊重各国历史文化、社会制度、文明形态差异，保护世界文化多样性。推动人工智能技术适配多元文化场景，促进各国文化的创造性转化和创新性发展，维护世界文明多样性和各国文化独特性。”这一要求把尊重文明多样性落实到人工智能开发和应用的具体过程之中，表明技术只有充分适应多元文化语境，才能真正促进不同文明的相互理解。

面向智能时代，既要发挥人工智能在文明成果整理、跨语言传播和知识阐释方面的优势，也要坚持文明平等、尊重文化差异、维护历史真实，使技术进步更好惠及不同国家和人民。唯有如此，才能把人工智能的技术潜能转化为增进不同文明理解和包容的现实力量，为各美其美、美美与共的文明百花园注入新的活力，也为落实全球文明倡议、推动构建人类命运共同体作出更大贡献。
