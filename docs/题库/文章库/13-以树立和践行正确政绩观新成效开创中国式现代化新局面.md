# 以树立和践行正确政绩观新成效开创中国式现代化新局面

> 来源：求是网 · 2026-08-26 · 正文约 7865 字

习近平总书记近日作出重要指示强调：“树立和践行正确政绩观是一项长期任务，必须久久为功，不断巩固拓展学习教育成果，持续推动各级党组织和广大党员、干部立党为公、为民造福、科学决策、真抓实干，努力创造经得起实践、人民、历史检验的实绩。”8月24日，中央党的建设工作领导小组召开会议，深入学习贯彻习近平总书记重要指示精神，总结树立和践行正确政绩观学习教育，研究部署巩固拓展学习教育成果、建立树立和践行正确政绩观长效机制工作。

有什么样的政绩观，就有什么样的发展导向、工作作风、事业格局。“十五五”时期是基本实现社会主义现代化夯实基础、全面发力的关键时期，既充满战略机遇，也面临风险挑战。在全党开展树立和践行正确政绩观学习教育（以下简称“学习教育”），是立足“十五五”良好开局，以树立和践行正确政绩观新成效开创中国式现代化新局面的关键之举、决胜之要。通过学习教育，党员干部思想之基更牢固、为民之心更纯粹、担当之勇更充沛、实干之风更浓厚，有力促进了“十五五”开局起步各项工作，为以中国式现代化全面推进强国建设、民族复兴伟业提供了有力保障。

深学细悟习近平总书记重要论述，持续增强树立和践行正确政绩观的政治自觉、思想自觉、行动自觉

追求真理、笃行正道，是我们党成功攻克一道道难关的制胜密码。从地方工作到领航中国，习近平总书记对政绩观问题进行了持续而深刻的系统思考，作出了一系列立意高远、内涵丰富、思想深邃的重要论述，为新时代党员干部修身立德、干事创业提供了思想引领，为实现“十五五”规划美好蓝图、开创中国式现代化新局面提供了科学指南。

深刻阐明树立和践行正确政绩观的重大意义。习近平同志在地方工作期间就高度重视树立和践行正确政绩观，在浙江省委党校2004年秋季开学典礼上，系统论述了树立正确政绩观的重要性和紧迫性，指出“五重五轻”的问题，“归其一点都是因为没有树立正确的政绩观”。新时代以来，习近平总书记指出“政绩观问题是一个根本性问题，关乎立党为公、执政为民”，从党的执政根基、事业兴衰成败的高度阐明了政绩观问题的重大意义。这深刻启示我们，政绩观不单是工作方法或工作态度问题，更是“总开关”“总闸门”。政绩观偏一寸，发展路偏十里；政绩观正一分，事业兴进一程。树立和践行正确政绩观必须贯穿“十五五”时期规划编制、项目落地、政策执行等各环节，确保中国式现代化建设不偏向、不走样。

深刻阐明树立和践行正确政绩观的原则遵循。“两个维护”是党的最高政治原则和根本政治规矩。政绩观首先是政治观，树立和践行正确政绩观，本质上是践行对党绝对忠诚的政治誓言、落实令行禁止的政治要求。从在浙江强调坚决维护党中央的权威，共发一个声音，到在上海强调要更加坚定地在国家战略下思考和行动，讲政治、维护党中央权威的高度自觉贯穿习近平同志地方工作始终。新时代以来，习近平总书记反复强调维护党中央权威和集中统一领导，明确把“有没有游离党的路线方针政策和党中央重大决策部署”作为是否树立和践行正确政绩观的重要标尺。这深刻启示我们，贯彻落实“十五五”规划，必须杜绝本位主义、选择性执行，始终以“一颗心”站位顾大局、以“一盘棋”思维谋发展，统筹推进中国式现代化建设。

深刻阐明树立和践行正确政绩观的价值立场。人民立场是中国共产党的根本政治立场，人民幸福是共产党人一切奋斗的价值旨归。在正定，习近平同志顶住压力推动减征购；在福州，得知位于三坊七巷的林觉民故居面临拆除，马上召开现场办公会，当场决定保护下来、进行修缮，深刻指出：“要在我们的手里，把全市的文物保护、修复、利用搞好，不仅不能让它们受到破坏，而且还要让它更加增辉添彩，传给后代”；在上海，关注“拎马桶”等民生难题，指出“解决民生问题是为政的根本，改善民生状况是最大的政绩”。新时代以来，习近平总书记强调“为民造福是最大政绩”，指出“业绩好不好，要看群众实际感受，由群众来评判”，从为谁树政绩、树政绩的目的是什么、如何评判政绩等方面阐明了树立和践行正确政绩观的价值立场。这深刻启示我们，做好“十五五”时期各项工作，必须始终锚定民生导向，抓紧抓好就业、教育、医疗、养老、住房、基层治理等民生实事，让中国式现代化成果惠及全体人民。

深刻阐明树立和践行正确政绩观的思想境界。思想境界是政绩观的深层支撑。在《之江新语》中，习近平同志鲜明提出心无百姓莫为“官”，要拎着“乌纱帽”为民干事，把党和人民的事业放在第一位；鲜明提出要甘于做铺垫性的工作，甘于抓未成之事，不求急功近利的“显绩”，创造泽被后人的“潜绩”。新时代以来，习近平总书记深刻揭示党性在树立和践行正确政绩观中的决定性作用，指出“只有党性坚强、摒弃私心杂念，才能保证政绩观不出偏差”；要求党员干部发扬“前人栽树、后人乘凉”的精神。这深刻启示我们，只有不断加强党性修养，涵养“功成不必在我、功成必定有我”的精神境界，才能树牢正确政绩观，为确保一张蓝图干到底，完成“十五五”时期乃至更长时期的重要任务筑牢思想基础。

深刻阐明树立和践行正确政绩观的实践路径。大道至简，实干为要。在福州，习近平同志倡导“马上就办、真抓实干”；在浙江，身体力行反对虚功、崇尚实干。新时代以来，习近平总书记指出“真干才能真出业绩、出真业绩”，反复强调抓落实并要求不折不扣、雷厉风行、求真务实、敢作善为抓落实。这深刻启示我们，面对“十五五”时期发展新质生产力、推进乡村全面振兴等一系列艰巨复杂的硬任务，没有捷径可走、没有虚功可做、没有退路可选，必须以不折不扣的精神、雷厉风行的作风、求真务实的态度、敢作善为的担当，把各项部署抓细抓实抓落地，把美好蓝图变为经得起实践、人民、历史检验的实绩。

深刻阐明树立和践行正确政绩观的科学方法。实干不等于蛮干，担当离不开方法。创政绩既要拼干劲，更要讲规律。在宁德，为了带领当地人民摆脱贫困，习近平同志提出一系列符合地方实际的发展举措；在浙江，在经过细致调研和科学论证后提出“八八战略”，为浙江转变发展方式、破解发展难题开辟新路。新时代以来，习近平总书记强调要“尊重客观实际和群众需求，强化系统思维和科学谋划”，要求处理好稳和进、立和破、虚和实、标和本、近和远的关系。这深刻启示我们，贯彻落实“十五五”规划，必须植根“实际”的土壤，遵循“规律”的准则，以辩证眼光和系统思维兼顾速度与质量、发展与安全、当下与长远、全局与地方等关系，实现全面协调可持续发展。

深刻阐明树立和践行正确政绩观的重要抓手。政绩考核评价体系是一个“指挥棒”，为抓什么工作、用什么样的人树立起鲜明导向。习近平同志在浙江时提出衡量领导干部政绩“首先要坚持群众公认、注重实绩的原则”，既看经济指标，又看社会指标、人文指标和环境指标。新时代以来，习近平总书记强调“树立重实干、重实绩的用人导向”，完善推动高质量发展的政绩观考核评价办法，完善差异化考核评价体系，形成能者上、优者奖、庸者下、劣者汰的良好局面。这深刻启示我们，要把完善政绩考核评价体系作为树立和践行正确政绩观的重要抓手，围绕为民造福与推动高质量发展完善“考什么”，统筹显绩与潜绩完善“怎么考”，充分调动党员干部奋进“十五五”的积极性、主动性、创造性。

深刻阐明树立和践行正确政绩观的根本保障。管党治党责任的压紧压实，是正确政绩观落地生根的根本保障。“总揽全局，抓大事”“反对官衙作风，注重工作实效”……在正定，习近平同志主持制定关于改进领导作风的六项规定，立规矩、正风气，全县干部精神面貌、作风状态为之一振。新时代以来，习近平总书记强调“全面从严治党要更好发挥政治引领和政治保障作用”，并把健全主体明确、要求清晰的责任体系作为健全全面从严治党体系的重要内容，要求以责任主体到位、责任要求到位、考核问责到位，推动管党治党责任落实到位。这深刻启示我们，推动党员干部以正确政绩观贯彻落实“十五五”规划，既需要加强思想教育，也需要强化刚性约束。通过牵住责任制这个“牛鼻子”，把监督贯穿制定决策、推动落实、成效检验等各方面工作，对政绩观错位偏差及时纠偏正向，推动党员干部在遵规守纪、清正廉洁底线上锐意创新、放手干事，把既定的行动纲领、战略目标、工作蓝图一步步变为实景。

树立和践行正确政绩观是开创中国式现代化新局面的重要基础

政绩观是世界观、人生观、价值观在履职干事中的集中体现，直接决定党员干部干事创业的精神状态、奋斗方向和工作质效，深刻影响中国式现代化建设的推进节奏、发展成色和最终成效。党员干部肩负着制定政策和具体落实的重任，只有政绩观端正、事业观纯粹、权力观清醒，才能确保中国式现代化建设方向不偏、力度不减、举措不虚。

保持党的鲜明本色、确保中国式现代化正确方向的根本要求。中国式现代化是中国共产党领导的社会主义现代化，党的先进性和纯洁性决定中国式现代化的方向和底色。正确政绩观体现党的先进性本质，体现党的理想信念和使命担当。在学习教育中，党员干部以党的创新理论补钙壮骨，在思想上正本清源、在党性上淬炼提纯，牢固树立为民立业、实干立业、长远立业的鲜明导向，全党始终坚定理想信念、站稳人民立场，以立党为公、为民造福的本色驾驭复杂局面，牢牢掌握中国式现代化建设的领导权、主动权，使中国式现代化始终沿着正确道路坚定前行。

深化全面从严治党、锻造推进中国式现代化的干部队伍的重要途径。政绩观错误和偏差是导致一些党员干部言行失范甚至滑向腐败深渊的重要根源。“十五五”开局之年，恰逢地方领导班子换届、规划全面铺开，极易出现急功近利、“翻烧饼”、重短期轻长远等倾向。学习教育直击政绩观突出问题，深挖形式主义、官僚主义的思想根源，祛思想之尘、纠履职之偏、治作风之弊，使党员干部切实把正确政绩观刻印于心、外化于行，培养造就堪当民族复兴重任的高素质干部队伍，为中国式现代化建设提供坚强组织保障。

激发干事创业热情、提升中国式现代化发展质效与韧性的关键举措。“十五五”时期，外部遏制打压与内部转型压力叠加，各类矛盾风险增多，唯有以高质量发展的确定性方能抵御发展环境的不确定性。开局起步的精气神、攻坚克难的战斗力，源自正确政绩观。习近平总书记告诫党员干部，要“扎扎实实、踏踏实实地搞现代化建设”。学习教育是思想破冰、作风提效、能力升级的关键举措，推动党员干部坚持把高质量发展作为政绩观的重要内容，在因地制宜中找准自身定位、谋划发展路径，彻底走出“发展就是上项目、搞投资、扩规模”的路径依赖、思维误区，把干事热情、攻坚干劲转化为发展新质生产力、构建新发展格局、推进共同富裕等的持久动力。

涵养良好政治生态、确保中国式现代化行稳致远的重要保障。风清气正的政治生态是最好的发展环境、最强的发展底气。中国式现代化是一场久久为功的伟大事业，非一日之功、非一蹴之成。“十五五”时期承前启后，既要推动一系列战略任务取得突破，也要打基础、利长远，为中国式现代化巩固优势。盲目铺摊子、重显绩轻潜绩、数据造假等错误政绩观，透支发展潜力、贻误现代化进程。学习教育大力弘扬实事求是、求真务实的作风，引导党员干部辩证把握显绩与潜绩、速度与质量、当下与长远、局部与全局的关系，大力培育担当实干、接力奋进的良好政治生态，为如期基本实现社会主义现代化营造良好环境。

新时代以来政绩观系统性重塑，为中国式现代化成功拓展提供坚实思想保障

习近平总书记指出：“这次树立和践行正确政绩观学习教育在党中央坚强领导下，坚持把理论学习贯穿始终，真查实改政绩观偏差问题，着眼务实管用立好制度规矩，以严实作风一抓到底，取得明显成效，达到了预期目的。”党的十八大以来，以习近平同志为核心的党中央始终把纠治政绩观偏差作为推进全面从严治党的重要抓手，从观念层面到行动层面、从“关键少数”到“绝大多数”，持之以恒推动树立和践行正确政绩观，为中国式现代化成功拓展提供了坚实思想保障。

观念之变：从重显轻潜到显潜并重。过去一段时间，有的党员干部干事创业多少存在重显轻潜的思维惯性，认为抓工作必须摆到明面上，多做看得见、摸得着的事才算做出了真成绩，更愿意往大马路、大广场、大高楼等吸引眼球的工程上投入，对于民生兜底、生态修复等短期内难以出彩留名的工作避而远之。出现这样的情况，是政绩观上出了岔子。党的十八大以来，经过持续引导纠偏，特别是经过学习教育，党员干部不再一门心思盯着任期内快出成果，而是愿意沉下心，为地方长远发展多铺几块基石。实践证明，投入大、周期长，短期内出不了亮眼报表，却能给未来5到10年甚至几十年发展托住底、攒足后劲的事，和立竿见影、雪中送炭的事一样，都是老百姓真正需要、真心点赞的真政绩。当前，“十五五”规划蓝图已经铺开，必须把显绩抓扎实、用潜绩谋长远，一棒接着一棒跑，直到把规划中的长远目标变为人民群众看得见、摸得着、得实惠的发展实绩。

行动之变：从唯GDP论到坚持高质量发展成为正确政绩观的重要内容。过去，“以GDP论英雄”催生了粗放扩张、盲目铺摊、透支发展的短视行为，部分地区为追求增速排名、数据好看，不惜牺牲生态环境、透支民生福祉、挤占长远潜力，看似增速亮眼，实则隐患暗藏、后劲不足。党的十八大以来，以习近平同志为核心的党中央坚决破除“唯增速、唯总量、唯排名”的陈旧逻辑，构建起重质量、重效益、重结构、重长远、重民生的高质量发展综合考核体系，推动政绩评价从“数量导向”转向“质量导向”。考核标尺的变革，倒逼履职方式、发展逻辑的深刻转型：一方面，党员干部把更多精力投向产业升级、科技创新、生态治理、民生改善、风险防控等重要领域；另一方面，牵引和撬动社会发展实现从“规模扩张”向“质效提升”转变，使高质量发展从理念层面的共识，一步步变成落地生根、惠及群众的生动实践。

生态之变：从被动应对到主动自觉。政治生态是检验管党治党成效的“晴雨表”。正确政绩观的树立和践行，本质是党性的自觉淬炼、思想的主动升华，绝非他律约束下的被动应付、刻意为之。过去一段时间，有的地方政治生态处于“被动纠偏”状态，管党治党、正风肃纪多是上级督才抓、纪委推才动、问题出才治，陷入事发整治、事后整改、反复反弹的怪圈。这种“头痛医头、脚痛医脚”的治理模式，即使能一时压住乱象，却难以跳出“春风吹又生”的循环。党的十八大以来，以习近平同志为核心的党中央以刀刃向内的勇气重构政治生态，既拔烂树、治病树、正歪树，更护森林、固土壤、净生态，推动党员干部实现从“要我守规矩、要我树政绩”的外部约束，转变为“我要守初心、我要创实绩”的内在追求。这种跃升的价值观，使求真务实、久久为功成为常态，实干担当、为民造福成为自觉，清风正气、清正从政成为底色，为中国式现代化建设涵养了海晏河清、风清气正的政治生态。

以正确政绩观护航中国式现代化行稳致远

习近平总书记强调：“要经常性开展政绩观教育，重点抓好对地方党政正职、新提拔干部、年轻干部、关键岗位干部的教育培训，强化示范引领和反面警示，引导党员、干部始终以正确政绩观担当作为、履职尽责。要坚持常态化查改问题，对需要长期整改的政绩观偏差突出问题盯紧不放、跟踪问效，深化‘新官不理旧账’整改整治。”“十五五”开局之年，中国式现代化建设任务更重、要求更高、考验更大。越是任务繁重复杂，越要校准前进方向；越是处于关键节点，越要端正干事创业作风。必须巩固拓展学习教育成果，建立长效机制，把“立党为公、为民造福、科学决策、真抓实干”的总要求不折不扣落到具体行动中，以过硬政绩、优良作风、扎实成效奋力开创中国式现代化新局面。

强化理论武装，筑牢正确政绩观的思想根基。思想是行动的先导，理论上拎得清方向，干事创业才能踩得稳步子。树立和践行正确政绩观，首先要把思想“总开关”拧紧、价值“总坐标”校准，学深悟透习近平新时代中国特色社会主义思想，特别是习近平总书记关于树立和践行正确政绩观的重要论述，让理论滋养初心、让思想引领行动、让信念支撑实干。坚持学思用贯通、知信行统一，带着问题学、盯着实效悟、对着难题干，把理论学习的成果融入民生服务、乡村全面振兴、生态保护等一线，把正确政绩观融入血脉、刻入脑海、落到实处，贯穿决策部署、履职尽责全过程。

站稳人民立场，把准政绩的根本价值导向。为民造福是党员干部干事创业的出发点和落脚点。评判一项工作、审视一份政绩，不在于台账多么详实、报表多么亮眼，而在于群众是否认可、百姓是否满意、民生是否改善。奋进“十五五”，必须坚持人民至上的价值立场，彻底摒弃功利心态、“升官”思维、标签意识，从事任何谋划、推进任何项目，都首先从群众急难愁盼出发。常态化下沉基层、走访群众、摸清实情，多做雪中送炭的惠民实事、固本培元的长远好事、凝聚民心的关键大事，一步一个脚印、实打实做好扩充优质学位、升级养老服务等民生实事，让中国式现代化的成果更好惠及千家万户，让发展实绩充分转化为人民群众的获得感、幸福感、安全感。

坚持求真务实，从客观实际出发按规律办事。实事求是、求真务实，是共产党人的优良品格。树立和践行正确政绩观，关键要坚持和发扬我们党的优良传统，做决策、办事情立足本地实情、把握发展规律，不图表面热闹、不贪短期速成，谋划项目、推进工作先摸清家底、看清短板，坚决摒弃“拍脑袋决策、拍胸脯表态、拍屁股走人”的不良作风。落实“十五五”时期发展任务，必须坚持因地制宜、分类施策、精准发力，尊重发展规律、立足发展实际、守住发展底线，以“功成不必在我”的定力打基础、利长远，以“功成必定有我”的担当攻难题、促突破。

贯彻新发展理念，以正确政绩观引领高质量发展。发展观决定政绩观，政绩观引领发展路。“十五五”时期推动高质量发展，必须跳出“唯速度、唯增量”的形而上学认知，摒弃粗放扩张、透支资源的短视做法，切实把创新、协调、绿色、开放、共享的新发展理念贯穿规划制定、项目建设、成效评判全过程，算好发展质量、生态效益、民生普惠综合账，引导广大党员干部自觉以长远眼光谋划发展、以系统思维推进工作，多做培育科创动能、涵养绿色生态、完善配套体系、积蓄发展后劲的潜绩实事，推动高质量发展成色更足、生态底色更绿、民生温度更暖。

完善制度体系，以科学考核与鲜明用人导向护航干事创业。干部怎么干、事业怎么推、政绩怎么创，关键看导向怎么树、考核怎么定。习近平总书记强调：“要用好考核指挥棒，完善差异化考核评价体系，树立重实干重实绩的选人用人导向，让敢于负责、勇于担当、善于作为、实绩突出的干部受到重用。”推动“十五五”时期经济社会发展，必须建立健全覆盖干部选用、实绩评判、激励约束的制度体系，分层分类完善考核指标细则，杜绝一套模板、一套权重管到底、统到底，精准甄别一时之功与长久之效、表面之功与务实之绩，从制度层面纠治重显轻潜、重速轻质、重上轻下的浮躁倾向。坚持以实干论英雄、以实绩定取舍、以口碑辨优劣，在项目攻坚、民生服务、应急处置、基层治理一线考察干部，重点看干部推进工作是否遵循客观规律、谋划项目是否符合群众利益、攻坚克难是否敢啃硬骨头，坚决纠治投机取巧、虚浮不实、急功近利的行为，把甘创打基础利长远潜绩、群众口碑扎实、关键时候站得出顶得上的干部选出来、用起来。

征程万里风正劲，重任千钧再出发。站在“十五五”开局起步的历史节点，树立和践行正确政绩观，既是时代考题，也是使命答卷，更是党员干部的终身课题。面向未来，广大党员干部坚持把为民造福作为最大政绩，一茬接着一茬干、一棒接着一棒跑，一定能把“十五五”宏伟蓝图转化为美好现实，在推进中国式现代化的道路上交出经得起历史、实践和人民检验的崭新答卷。
