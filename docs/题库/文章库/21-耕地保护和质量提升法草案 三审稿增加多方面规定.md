# 耕地保护和质量提升法草案 三审稿增加多方面规定

新华社北京8月25日电（记者 王立彬）耕地保护和质量提升法草案8月25日提请十四届全国人大常委会第二十四次会议第三次审议。草案三审稿进一步增加了有关人才、资金、补偿等方面的规定。

此前，耕地保护和质量提升法草案二次审议后，进一步广泛征求社会公众意见，有的常委会组成人员、全国人大代表和社会公众提出，高水平的科技人才队伍对于提升耕地保护和质量提升工作水平至关重要，建议增加鼓励高等学校、科研院所等加强耕地保护和质量提升方面人才培养的规定，草案三审稿增加了相应规定。

有的意见提出，近年来，违法使用、占用高标准农田建设资金问题较为突出，严重影响了高标准农田建设质量，应进一步强化对高标准农田建设资金的监督管理。草案三审稿增加规定，禁止任何单位和个人截留、挤占或者挪用高标准农田建设资金。

国家粮食主产区在耕地保护和粮食安全方面发挥了重要作用，为进一步体现对粮食主产区的利益补偿，草案三审稿增加规定，国家健全粮食主产区利益补偿机制，完善对粮食主产区和产粮大县的财政转移支付制度，健全粮食产销区省际横向利益补偿机制。

黑土地是最宝贵的耕地，为进一步加大对黑土地的保护力度，草案三审稿增加规定，保护黑土地的优良生产能力，确保黑土地总量不减少、功能不退化、质量有提升、产能可持续。

为了防洪安全，草案三审稿增加规定，河湖管理范围内的土地原则上不作为补充耕地来源。草案三审稿还增加了对沙化、风蚀、水蚀耕地开展综合治理，预防和治理水土流失的规定。
