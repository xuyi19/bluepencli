# 为自动驾驶划定安全红线

> 来源：中国青年报 · 2026-08-26 · 正文约 2476 字
> 主题：民生保障
> 原文：https://zqb.cyol.com/pc/content/202608/26/content_429898.html

---

中青报·中青网记者 刘言
（2026年08月26日  01版）

一部与每名交通参与者息息相关的法律迎来新一轮重要修改。8月25日，道路交通安全法修订草案（以下简称“修订草案”）提请十四届全国人大常委会第二十四次会议初次审议。

现行道路交通安全法自2004年施行以来，先后于2007年、2011年、2021年修正了个别条款。此次提请审议的修订草案共9章170条。司法部部长贺荣受国务院委托向大会作草案说明时介绍，修订草案妥善处理道路交通安全与自动驾驶汽车、电动自行车产业发展、通行效率提高等关系，聚焦“醉驾”“僵尸车”“超标车”治理和电动自行车、“暴走团”管理等突出问题，有针对性地完善制度措施，在维护道路交通安全的同时，推行便民举措，便利群众出行。

增设自动驾驶汽车专章

修订草案专门设置了“自动驾驶汽车的特别规定”专章。草案明确界定，自动驾驶汽车是指在设计运行条件下代替驾驶人持续自动地执行全部动态驾驶任务的汽车；辅助驾驶功能是指在设计运行条件下辅助驾驶人执行部分动态驾驶任务的功能。

修订草案还进一步明确规则边界，未激活自动驾驶功能的自动驾驶汽车和驾驶仅具备辅助驾驶功能的汽车上道路行驶，按照非自动驾驶汽车的规定管理。

西南政法大学教授、高等研究院院长郑志峰对此解读说，依据相关国家标准的规定，辅助驾驶和自动驾驶是两种完全不同的技术形态——辅助驾驶系统仅仅是协助用户承担动态驾驶任务，开车的仍然是用户，而自动驾驶是系统替代用户承担动态驾驶任务，开车的已经是系统。

“这也意味着现行道路交通安全法关于传统机动车的规定是没有办法直接适用于自动驾驶汽车的。”郑志峰告诉中青报·中青网记者。

郑志峰表示，这是我国首次以法律的形式承认自动驾驶汽车的合法性，并对其道路通行规则作了规定，“对于自动驾驶汽车产业有重要意义，既为产业发展提供助力，也划定了安全底线”。

“辅助驾驶并未真正彻底解放用户，驾驶员的身份是没有改变的，驾驶员仍然需要手握方向盘，观察道路交通环境，随时准备接管。而自动驾驶汽车是不一样的，用户在系统运行期间是无需承担动态驾驶任务的，甚至有的自动驾驶汽车可以彻底去除方向盘。”郑志峰表示，修订草案对两者进行区分非常必要，对于整顿现有的市场乱象、警示消费者有重要的意义。

针对行业宣传乱象，修订草案要求车企如实告知自动驾驶功能设计运行条件，不得作出与之不相符的产品说明、商业宣传等。郑志峰指出，实践中，有用户在使用辅助驾驶的时候过度信任系统的能力，导致在紧急情况下没能及时接管而产生严重的事故，“本次修订可以很好地划清两者的界限，防止企业虚假或者夸大宣传”。

在责任认定层面，修订草案还明确，自动驾驶汽车在自动驾驶功能激活状态下发生道路交通安全违法行为的，由自动驾驶汽车生产企业、进口企业接受处理。

“自动驾驶汽车强调机器驾驶取代手动驾驶，原先以驾驶人、手动驾驶行为、驾驶过错为基础展开的责任规则需要调整。”郑志峰对此解读说，“简单来说，传统机动车是驾驶人在开车，出了事故当然是人负责，而自动驾驶汽车是系统在开车，出了事故再找驾驶人的责任就不太合适。”

在郑志峰看来，修订草案这一规定，很好地契合了自动驾驶汽车的技术特征，有助于打消消费者的用车顾虑。

提高电动自行车限速，补齐安全驾驶规定

针对群众高度关注的电动自行车的管理问题，修订草案从源头管控与通行规则两端发力，要求非机动车应当符合强制性国家标准，禁止生产、进口、销售不符合强制性国家标准的非机动车（国家另有规定的除外）。不符合强制性国家标准的残疾人机动轮椅车、电动自行车不得上道路行驶。

修订草案还禁止擅自改动已登记的非机动车的结构、构造、特征或者安全技术参数。要求电动自行车生产企业应当采取有效措施，完善防篡改要求，防止在销售、使用环节对安全技术参数进行改动。

在通行速度规则上，修订草案明确，电动自行车在非机动车道内行驶时，最高时速限制从15公里调整为20公里。

“这是立法的进步。”清华大学交通研究所副所长杨新苗告诉记者，20多年前他曾参与道路交通安全法立法讨论会，当时在北京街头实测，人力自行车的平均速度就达到了15公里/小时，“把它作为电动自行车的最高限速，显然和现实情况不符。”

杨新苗同时建议，在此基础上，可以进一步科学区分管理电动自行车的主要类型，将电驱动型电动自行车，与轻量化的电助力自行车区分管理，“电助力自行车必须要脚踏起来才能前进，电机只是提供额外的助力，让骑行变得更轻松，回归非机动车属性和定位。”杨新苗认为，可以借鉴欧洲主要国家的做法，“对电助力自行车几乎不用额外管理，能节约大量的管理资源”。

修订草案还对电动自行车的安全驾驶作出细化要求，规定驾驶电动自行车在道路上行驶不得有逆向行驶、超速行驶、违反交通信号通行以及拨打或者接听手持电话、观看视频等妨碍安全驾驶的行为；电动自行车的驾驶人和乘车人应当按照规定戴安全头盔等。

靶向治理“盲驾”“暴走团”“僵尸车”等民生热点

修订草案围绕道路交通安全行为规范增加了具体要求。在规范机动车驾驶行为方面，除了禁止“酒驾”“毒驾”“飙车”外，还规制驾驶时拨打或者接听手持电话、观看视频的“盲驾”。对“盲驾”并造成交通事故或者其他严重后果的，草案规定处200元以上500元以下罚款，可以并处暂扣3个月机动车驾驶证。

修订草案还对乘车人、行人的交通参与行为进行规范。为了防止“开门杀”，修订草案要求开关车门时，机动车驾驶人、乘车人应当注意观察，驾驶人应当提醒乘车人注意安全。

为规范“暴走团”，修订草案规定，未经许可，任何单位或者个人不得占用道路从事非交通活动。公安机关交通管理、交通运输、住房城乡建设等主管部门应当加强道路交通安全监督管理，发现违法占用道路从事文化娱乐、体育健身等非交通活动的，应当及时劝阻、制止或者依法处理。

针对道路停放“僵尸车”问题，修订草案规定停放超过120日，并根据其位置、状态等情况，有合理理由认定已被弃置的机动车可以被认定为废弃机动车。禁止在道路上停放废弃机动车。
