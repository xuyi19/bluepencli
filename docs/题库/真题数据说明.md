# 国考申论真题库 · 数据说明

> 本文件由 `.tools/exams/report_doc.py` 自动生成，数字全部现算。
> 重新生成：`backend/.venv/Scripts/python.exe .tools/exams/report_doc.py`

## 一句话

**53 套国考申论真题（2008–2024）/ 239 道题**已结构化：
每套卷带整卷给定资料，每道题带题干、作答要求、分值、字数与参考答案。

其中 **40 套（2008–2021）随开源版分发**，**13 套（2022 起）为私有资产** —— 不进仓库、不进分发产物，
由作者定向分发 `.bpq` 题库包、使用者自行导入。

## 数据在哪儿

| 用途 | 路径 |
|---|---|
| 提取/校验脚本（不参与构建） | `.tools/exams/` |

| 统一题库入口 | `frontend/src/data/questions.js` |

## 流水线

```
37 份真题 PDF
  ↓ extract.py   ① 文本提取（PyMuPDF）② 分题 ③ 结构化
  ↓              └ 用「（N分）」+「字数要求」双锚点切题；用行首缩进几何还原段落
  ↓ qc.py        ④ 预解析（采分点证据命中，需 LLM，本版未做）
  ↓             ⑤ 校准：分题/字段/分值合计 100/字数/答案齐全
  ↓             ⑥ 入库：schema 校验
  ↓ to_frontend.py  按年份分两层产出：real-exams/（公开）+ real-exams-private/（私有）
  ↓ export_bpq.py   私有卷 → .bpq 题库包（带使用者水印），定向分发
前端题库（公开卷随包，私有卷由使用者导入）
```

分题锚点用的是「（N分）」而不是题号，因为各卷的题号写法有四种
（`第一题：` / `1.` / `（一）` / 完全无编号），只有分值结尾是每题都有的。

## 已知限制

1. **源 PDF 多为考生回忆/OCR 版**，不是官方排版件。错字丢字已尽可能校订，
   但不排除仍有残留；用法上把它当「可靠的练习题」而非「法定文本」。
2. **第④步「LLM 预解析采分点」未做**。计划里这一步用于给每道题生成采分点及其
   在材料中的证据串；本版只做到「结构化 + 校准」，采分点仍由五位老师在批改时现场判断。
3. **答案有两套的卷只取第一套**（如 2021 副省级 PDF 里同时有 H/F 两版答案）。
4. **一题多小问按大题合并**（2016 地市级第三题）：两个小问各自的要求都保留，
   字数取和（450 字），练习时当作一道题写。
5. **`.bpq` 目前是明文的**，带使用者水印与 FNV-1a 校验和（防损坏，不防伪造）；
   AES-256-GCM 加密与 ECDSA 签名按计划留到 V2，格式里已预留字段。
